# Thermo Infinity Quiz

Individual practice on thermodynamic properties: classify the phase of an assigned state, determine its properties, and place it on two property diagrams.

## Live tool

[Open Thermo Infinity Quiz](https://nuhaaljuneidi.github.io/thermo-infinity-quiz/)

## Features

- Each student is assigned one of 40 official cases from their ERAU student email; the case is restored if they return.
- After submitting the assigned case, students continue with unlimited practice cases.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
